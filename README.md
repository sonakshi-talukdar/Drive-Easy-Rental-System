# Drive Easy Rental System

## About the Project
Drive Easy Rental System is a Java-based vehicle rental management application developed as part of my internship project.

It helps manage vehicles, customers, rental bookings, payments, and reports through a menu-driven interface.

## Features
- Add, view, and search vehicles
- Register and view customers
- Create rental bookings
- Calculate rental cost based on daily rate and rental duration
- Cancel rental bookings
- Process simulated Cash, Card, and UPI payments
- Generate reports for vehicles, customers, bookings, and successful payment revenue
- Validate customer registration, vehicle availability, and rental duration

## Technologies Used
- Java
- Object-Oriented Programming (OOP)
- ArrayList
- Interfaces and polymorphism

## How to Run

1. Install the Java Development Kit (JDK).
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Compile the Java source:

   `javac VehicleRentalManagementSystem.java`

5. Run the application:

   `java VehicleRentalManagementSystem`

## Note
This project uses in-memory ArrayLists. Data is not permanently stored and resets when the application is restarted.
